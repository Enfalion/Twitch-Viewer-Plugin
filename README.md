# 💜 OpenDeck Twitch Viewer Plugin (`xyz.enfalion.twitchviewer`)

Ein plattformübergreifendes **OpenDeck & Stream Deck Plugin** speziell für **Twitch-Zuschauer** (Windows, Linux & macOS) mit **automatischer Deutsch/Englisch Sprach-Erkennung** und **vorinstallierter Standard-Client-ID für 1-Klick Twitch Login**.

* **Author:** Enfalion (`enfalion.xyz`)
* **Bundle ID:** `xyz.enfalion.twitchviewer`
* **Repository:** https://github.com/Enfalion/Twitch-Viewer-Plugin

---

## ✨ Features (v1.3.1)
- **⚡ Echter 1-Klick Twitch Login & Logout:** Dank vorinstallierter Standard-Client-ID reicht ein einziger Klick auf *"1-Klick Twitch Login"*, um dein Konto per 8-stelligem Code auf `twitch.tv/activate` zu verbinden!
- **🌍 Dynamische Sprache (DE & EN):** Erkennt automatisch die in OpenDeck / Stream Deck eingestellte Sprache und übersetzt alle Einstellungs-Menüs, Erklärungen sowie Tasten-Texte live!
- **👤 Favorite Streamer (100% Optional):** Zeigt das echte Profilbild deines Lieblingsstreamers (Offline = Graustufen, Online = Farbig + Roter Rahmen + Zuschauerzahl + Kategorie – jedes Element einzeln zu- und abschaltbar!).
- **🔄 Dynamic Live Slot (Auto-Rotierend):** Rotiert automatisch alle 10 Sekunden durch alle deine aktuell live streamenden Favoriten oder lässt sich per Lang-Druck weiterschalten.
- **⏭ Dynamic Live Switcher:** Zeigt live an, wie viele deiner Favoriten gerade online sind, und schaltet alle Live-Slots beim Drücken weiter.
- **🥷 Quick Chat / !lurk (Mit Kanal-Icon):** Zeigt das Profilbild des gewählten oder zuletzt aktiven Streamers und sendet bei kurzem Druck sofort `!lurk` oder deine Wunsch-Nachricht.
- **📺 MultiTwitch Split-Screen:** Öffnet mehrere Streams nebeneinander in einem einzigen Browser-Fenster.
